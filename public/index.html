專題內容

工研院量子陀螺儀計畫

參與量子陀螺儀研究計畫，包含銣原子飽和吸收光譜與馬赫－曾德爾干涉儀，建立雷射穩頻與拍頻量測系統。

研究內容包含：

  • 架設銣原子飽和吸收光譜（SAS）系統，解析原子超精細能階結構。
  • 調整 Pump / Probe 光束功率與光路配置，改善譜線展寬與背景訊號。
  • 使用 Python 進行吸收光譜分析與擬合，取得吸收峰中心位置及線寬。
  • 結合頻率調變與鎖相放大器，建立具有零交越點的雷射穩頻誤差信號。
  • 利用 AOM 建立約 40 MHz 頻率差的光學外差系統。
  • 透過示波器與 FFT 分析，在 38.9 MHz 處量測到拍頻訊號。
  • 調整分光比例與光束強度，作為後續旋轉角度與相位變化量測基礎。

積分器電路設計與製造

為雷射穩頻與雷射功率控制系統設計積分器回授電路。

  • 分析減法器、積分器、衰減器、Buffer 與正負電壓切換等電路。
  • 利用麵包板進行元件與模組測試，量測不同輸入波形之輸出結果。
  • 分析積分時間常數對輸出振幅與波形斜率的影響。
  • 使用 EasyEDA 完成 PCB 電路設計。
  • 完成元件挑選、焊接、組裝、BNC 配線與整機測試。
  • 製作完成之積分器可作為雷射功率穩定與回授鎖頻系統使用。
